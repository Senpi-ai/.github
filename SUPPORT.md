# Getting help with Senpi

- **Using Senpi** (your agent, strategies, deposits and withdrawals, plans): start at the [support page](https://senpi.ai/resources/support), or email **support@senpi.ai**.
- **Guides:** [senpi.ai/resources](https://senpi.ai/resources). For AI agents and assistants: [senpi.ai/resources/llms.txt](https://senpi.ai/resources/llms.txt).
- **A bug or a question about code in one of our repositories:** open an issue in that repository.
- **A security problem:** follow [SECURITY.md](SECURITY.md) and don't post it publicly.

Senpi staff never message you first and never ask for your seed phrase, private key or a one-time code.
