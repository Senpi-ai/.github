# Security at Senpi

Senpi is a non-custodial AI trading agent for Hyperliquid. This policy covers every public repository in the [Senpi-ai](https://github.com/Senpi-ai) organization and Senpi's own sites.

## Report a vulnerability

Email **support@senpi.ai** with "Security" in the subject line. Include what you found, where (repository, file or URL), how to reproduce it, and what an attacker could do with it.

- Please don't open a public issue or pull request for a security problem.
- Please don't access, change or move anyone else's data or funds while testing.
- We reply to every report and keep you updated until it is fixed.

## Official Senpi sites and accounts

- Websites: **senpi.ai** and its subdomains, such as **mcp.senpi.ai**
- Code: **github.com/Senpi-ai**
- X: [@senpi_ai](https://x.com/senpi_ai)

Look-alike domains such as senpia.ai are not Senpi.

## Senpi staff will never

- send you a direct message first, on any platform
- ask for your seed phrase, private key, password or a one-time code
- ask you to send funds, connect your wallet to a site that is not senpi.ai, or install software from a link in a message

If someone claiming to be Senpi does any of these, it is not us. Report it to support@senpi.ai.
